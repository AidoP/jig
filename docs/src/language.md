# The configuration language

A project is configured by the `Jig` file at its root, a file of statements, each on a line of its own, with its attributes on the lines after it, indented by 4 spaces. A statement can be preceded by meta-statements, which start with `@`, and can `use` other files of statements. The pages of this chapter describe the statements, the meta-statements, the expressions which give values, and the attributes of each kind of statement.
